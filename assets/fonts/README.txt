The interface fonts, shipped with the game. Both are under the SIL Open Font License 1.1; each family's licence is
beside it. Taken unmodified from https://github.com/google/fonts (ofl/), renamed to the names UITheme loads.

  Title.ttf   IM FELL English Roman (Igino Marini; IMFeENrm28P.ttf)   titles and headings   IMFell-OFL.txt
  Body.ttf    Alegreya Sans Regular (The Alegreya Sans Project Authors)   body text      AlegreyaSans-OFL.txt

UITheme loads them as bytes; a missing file falls back to Godot's own font (Mono.ttf is not shipped).
